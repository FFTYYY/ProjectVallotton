Vallotton

你的AI绘图工作室

Vallotton本质上是一个AI绘图工作流，目标是用一种自然语言的交互方式来调用标签式的绘图模型（NovelAI V5），同时解决一些这类模型存在的问题，例如画风的一致性、原创人物的可复用性等，以及加入自主规划、连续生成、自主反思等能力。

Vallotton是什么

Vallotton是一个绘图工作室。其形态类似于ChatGPT，每个任务以对话的形式组织。Vallotton可以按照你的要求画画、修改本对话内已有的图、讨论已有的图等等，也可以纯聊天。（月初：GPT Astra，给我背九九乘法表。月末：我看Vallotton的编程能力也不错啊）

本质上，Vallotton是一个结合了大语言模型（我们目前默认用Deepseek V4 flash）与NovelAI V5的工作流。Vallotton的核心流程很简单，就是用语言模型将用户的自然语言需求翻译成NovelAI能理解的Danbooru风格的提示词，再由NovelAI生成图像。然而，如果只是暴力地这样做，会遇到很多问题，比如同一个人物在不同的图里长得不一样、衣服的细节会变化、画风会不一致，以及无法做局部修改等等。Vallotton引入了一套复杂的流程来尽可能规避这些问题。

理解Vallotton的这个核心流程至关重要，因为Vallotton能做的事情本质上受到其内部的语言模型和NovelAI的能力限制。例如，其非常擅长绘制热门动漫IP的人物，以及支持特定画师风格tag1，因为NovelAI针对这些场景进行过专门训练。NovelAI还有专门的风景画和福瑞（？）数据库，Vallotton在这些类型上的创作也很出色。然而，其无法像ChatGPT（背后是gpt-image-2.5）那样创建有真实感图像。

在开始之前，你需要了解并准备什么

NovelAI你需要一个NovelAI的订阅账号和它的persistent token。Vallotton的出图会使用订阅的用量。
大语言模型你需要一个DeepSeek的API key（也支持Grok，见部署教程）。
本机运行要在自己的电脑上运行Vallotton，你需要一台可以联网的Windows、macOS或者Linux的电脑。Python等运行环境（如果本地没有）会由启动脚本自动联网下载。
服务器部署要在服务器上部署Vallotton，你需要一台公网可访问的Linux机器以及一个域名。
